what is escape sequence?

An escape sequence is a combination of characters that represents a special character or action in strings and text. It starts with a backslash (\) followed by one or more characters

   what is f strings?

   An f-string is a way to embed variables or expressions directly inside a string. You just put an f before the opening quote, then use {} curly braces to insert values.
